# How This Path Will Work

*Section 1: Introduction · Lesson 1 of 30 · about 30 min*

## Introduction

Welcome! This path takes you from your first call to an AI model all the way to a tested, secure AI app that you can put online.

Each lesson points you to free material, then gives you something to build. Please don't skip the building. That's where the real learning happens.

## Lesson overview

By the end of this lesson, you should be able to:

- How the path is organized.
- How to split your study time.
- How to keep a learning log.

## Assignment

1. Look over the [course map](README.md). There are 6 sections and 4 projects. The whole path takes about 30 weeks.
2. Pick a fixed time to study, 6 days a week, and put it in your calendar. 90 minutes a day is enough.
3. Create a private GitHub repository called `ai-engineer-path` and add a file called `log.md`.
4. Split each session like this: about 30 minutes learning, 45 minutes building and 15 minutes writing in your log. In the log, write what you did, what broke and how you fixed it.
