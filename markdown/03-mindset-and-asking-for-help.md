# Mindset and Asking for Help

*Section 1: Introduction · Lesson 3 of 30 · about 45 min*

## Introduction

You will get stuck. Everyone does, and it's a normal part of learning.

This lesson gives you two habits: ask clear questions, and understand every line of code you keep, even code an AI wrote for you.

## Lesson overview

By the end of this lesson, you should be able to:

- Where to ask for help.
- How to ask a question people can answer.
- The explain-your-code rule.

## Assignment

1. Reread The Odin Project's [Asking for Help](https://www.theodinproject.com/lessons/foundations-asking-for-help) lesson. The same tips apply here.
2. Join the [DataTalks.Club Slack](https://datatalks.club/slack.html) and find the `#course-llm-zoomcamp` channel. Always search the [Zoomcamp FAQ](https://datatalks.club/faq/llm-zoomcamp.html) before you post.
3. Join the [Hugging Face Discord](https://hf.co/join/discord). You'll use it in the agents section.
4. Copy this rule to the top of your log: “Before I commit code, I can explain what it does and why. In every project, I make at least one change without AI help.” Interviewers check this, so it's worth the effort.
