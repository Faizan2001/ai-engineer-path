# Mindset and Asking for Help

*Section 1: Introduction · Lesson 3 of 42 · about 1 hour*

## Introduction

> **Everyone gets stuck. What matters is how you ask for help.**

You will get stuck. Everyone does, and it's a normal part of learning.

This lesson gives you two habits: ask clear questions, and understand every line of code you keep, even code an AI wrote for you.

**After this, you can** get fast answers to good questions, and defend every line you commit.

**The skill that lasts:** owning code you didn't type. AI writes more and more code, so checking it well matters more and more.

## Lesson overview

By the end of this lesson, you should be able to:

- What to do when you're stuck.
- How to ask a question people can answer.
- The explain-your-code rule.

## Assignment

1. Read The Odin Project's [Motivation and Mindset](https://www.theodinproject.com/lessons/foundations-motivation-and-mindset) lesson, especially the part about what to do when you're stuck.
2. Reread their [Asking for Help](https://www.theodinproject.com/lessons/foundations-asking-for-help) lesson. The same tips apply here.
3. Join the [DataTalks.Club Slack](https://datatalks.club/slack.html) and find the `#course-llm-zoomcamp` channel. Search the [Zoomcamp FAQ](https://datatalks.club/faq/llm-zoomcamp.html) before you post. Join the [Hugging Face Discord](https://hf.co/join/discord) too.
4. Copy this rule to your log: “I can trace and check the code I keep.”
5. Here is why. In a [study of 52 developers](https://www.anthropic.com/research/AI-assistance-coding-skills), the group that used AI while learning a new Python library scored lower on a quiz straight afterwards. It was a small study, so treat it as a warning, not proof. Use AI to explain an idea or give a hint. Before you run code, predict what it will do. Then run it and explain any difference yourself.
6. If you want a study buddy, post a short hello in the Zoomcamp Slack with your weekly goal. You can also start alone: at each project, record a short demo and ask for one specific piece of feedback. If nobody replies, check your work against the project's checks and write down one thing you're unsure about.
